# 几秒之前 (Seconds Ago)

一个基于时间循环的生存射击游戏，使用 Godot 4.5 开发。

## 游戏简介

在《几秒之前》中，你将陷入一个默认10秒的时间循环。每一轮循环中，你的所有行为都会被记录下来，并在下一轮循环中以"幽灵"的形式重现。这些幽灵会与你在同一空间中行动，创造出独特的挑战体验。

## 核心玩法

### 时间循环机制
- 每轮游戏时间为10秒（可在设置中调整）
- 当时间结束或玩家死亡时，循环重新开始
- 每次循环会记录玩家的所有行为数据

### 幽灵系统
- **幽灵玩家**：重现你上一轮的操作，包括移动、射击、动画等
- **幽灵敌人**：根据之前循环的敌人行为数据生成
- 幽灵与玩家同时存在于当前循环中，增加了生存难度

### 游戏目标
- 尽可能在循环中生存更长时间
- 学习并适应幽灵的行为模式
- 找到最佳生存策略来突破记录

## 操作控制

- **移动**: WASD 键或方向键
- **射击**: 鼠标左键
- **瞄准**: 鼠标位置

## 游戏特色

### 智能敌人
- 敌人会根据记录的玩家位置数据追踪
- 具有攻击性和移动模式
- 会在与玩家碰撞时造成伤害

### 流畅的游戏体验
- 物理引擎驱动的子弹系统
- 屏幕震动反馈
- 粒子效果（脚步尘土）
- 背景音乐和音效系统

### 数据记录系统
- 实时记录玩家位置和动画状态
- 保存子弹发射数据（位置、方向）
- 记录敌人行为和位置信息
- 完整的时间轴回放机制

## 技术特点

- **引擎**: Godot 4.5
- **开发语言**: GDScript
- **游戏类型**: 2D 动作/射击/生存
- **核心机制**: 时间循环、数据记录、回放系统

## 核心系统

### 1. 数据记录系统 (global.gd)
- 管理所有循环的游戏数据
- 包括玩家位置、子弹轨迹、敌人状态等
- 为幽灵回放提供数据支持

### 2. 玩家系统 (player.gd)
- 角色移动和动画控制
- 射击机制和子弹生成
- 实时数据记录
- 尘土粒子效果

### 3. 敌人系统 (enemy.gd)
- 智能追踪算法
- 幽灵敌人的行为回放
- 与玩家的交互逻辑

### 4. 游戏循环 (game.gd)
- 时间管理和UI更新
- 实体生成和清理
- 循环过渡效果

## 设计理念

《几秒之前》探索了时间循环在游戏中的应用，通过让玩家与自己的"幽灵"互动，创造出一个独特的自我挑战体验。每一轮循环都是一次学习机会，玩家需要观察、适应并改进自己的策略。

这种设计不仅增加了游戏的深度，还创造了一个持续的改进循环，让玩家不断追求更好的表现。
